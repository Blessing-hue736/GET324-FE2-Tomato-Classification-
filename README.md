GET 324 — Lab Exercise 10 (Mini-Project)

Group FE 3 — Healthy Tomato vs Tomato Early Blight
A binary image classification web app that identifies whether a tomato leaf is healthy or shows signs of early blight, using a MobileNetV2 transfer learning model deployed with Streamlit.

Project Structure
├── app.py                     # Streamlit application
├── requirements.txt           # Python dependencies
├── notebooks/
│   └── train_model.ipynb      # Data prep, training, evaluation
├── model/
│   └── tomato_model.h5        # Trained model (generated by the notebook)
└── README.md
Dataset
PlantVillage dataset (Kaggle) — Tomato_healthy and Tomato_Early_blight classes.

How to Run Locally:
git clone (https://github.com/Blessing-hue736/GET324-FE3-Tomato-Classification-.git)
cd GET324-Fe3 -Tomato-Classification-
pip install -r requirements.txt
streamlit run app.py

How to Train the Model:
Download the PlantVillage dataset from Kaggle (see notebooks/train_model.ipynb for instructions).
Open and run notebooks/train_model.ipynb top to bottom.
The trained model is saved to model/tomato_model.h5.

Deployment:
Deployed on Streamlit Community Cloud: https://get324-fe3-tomato-classification.streamlit.app/
